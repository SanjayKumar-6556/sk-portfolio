## In one line

Two related collection systems: scrapers that pull public job-board listings, and scrapers that
gather information about industry services — the second using Gemini to turn page content into
structured records rather than depending on hand-written selectors.

**Skills demonstrated:** building data-acquisition services, structured extraction from
unstructured web pages, applying an LLM where a parser is the wrong tool, feeding internal
systems with collected data.

## Context

Internal work at Nestack Technologies (AI engineer, March 2025 – present).

The company needed public information it did not have in any system: job listings from boards,
and information about services offered across an industry. Both are the same problem wearing
different clothes — the data is public, it is spread across many sites, none of those sites
agree on a format, and none of them are obliged to keep their markup stable.

## What I built

- **Job-board scrapers** that collect listings from public boards.
- **Gemini-based scrapers** that collect industry-service information, using the model to read
  page content and return structured fields.

## Why an LLM belongs in one of these and not necessarily the other

A conventional scraper encodes the page's structure into the code: find this container, take
that attribute. That is fast, cheap and exact — and it is also the thing that breaks silently
the day a site is redesigned, which for a long tail of small, heterogeneous sites is
continuously.

Using a model for extraction moves the brittleness. Instead of encoding one site's layout, you
describe the fields you want and let the model find them, which is what makes a long tail of
differently-shaped sources tractable at all. The costs are real and worth stating plainly: every
page costs an API call, extraction is no longer deterministic, and "the model returned something
plausible" is not the same as "the model returned something correct". That is why the two
systems are not built identically — a well-structured board with a stable layout does not need a
model, and paying for one there would be waste.
