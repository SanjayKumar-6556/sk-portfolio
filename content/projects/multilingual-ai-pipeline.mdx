## Overview

End-to-end workflow that generates localized prompt packs, validates them with bilingual reviewers when needed, and blocks releases when regression tests fail.

## The Problem

Translating prompts verbatim broke tone and safety constraints; teams lacked a single pipeline tying linguistic QA to deployment gates.

## Architecture

Source prompts live in git; CI expands locale matrices, runs automated semantic checks, and attaches reviewer approvals per locale tier.

## Key Engineering Challenges

### Safety parity

Different languages triggered different refusal patterns; golden transcripts per locale caught drift.

### Evaluation debt

Lightweight LLM judges supplemented human spot checks with explicit scorecards.

### Operational overhead

Automerge rules balanced velocity vs scrutiny based on risk classes.

## Workflows / Pipelines

1. Author updates canonical prompt JSON.
2. CI generates translations + schema validates structure.
3. Eval harness runs scenario suites per locale.
4. Approved bundles publish to edge config.

## Stack & Infrastructure

Python services, translation vendors via adapters, artifact registry for frozen prompt bundles.
