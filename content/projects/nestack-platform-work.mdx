## In one line

The company ran campaigns out of a third-party CRM and kept no campaign data of its own. I
designed the MySQL schemas, backend APIs and dashboards that changed that, built the
notification services the internal team runs on, and took over a set of existing PHP
applications.

**Skills demonstrated:** relational data modelling from scratch, backend API and dashboard
delivery, production Python automation, taking ownership of inherited code, working inside
constraints set by third-party tools.

## Context

Internal work at Nestack Technologies (AI engineer, March 2025 – present).

When a business runs entirely on a third-party CRM, the data is not really theirs. It is
queryable only through someone else's interface, joinable only in the ways that interface
allows, and it leaves with the vendor. There was no local database for campaigns at all — which
means no history you control, no analysis that the CRM's screens do not already offer, and
nothing for internal tools to build on.

## What I built

**Campaign databases.** I designed the MySQL schemas, backend APIs and dashboards that give
campaign activity a home inside the company rather than only inside the CRM. This is the foundation piece: nothing else
on this page — notifications, internal tooling, reporting — is possible while the only copy of
the data lives behind a vendor's API.

**Notification services.** Production Python automation for internal business workflows,
including the services that tell the internal team when something has happened rather than
requiring someone to notice it. Internal notification plumbing is unglamorous and it
is exactly the difference between a system people trust and a system people re-check by hand.

**Inherited PHP applications.** I took over a set of existing PHP applications and rebuilt a
number of their features. Inheriting an application someone else wrote, and shipping changes to
it without a rewrite, is a different skill from starting clean: you are reading intent out of
code, keeping behaviour that people depend on, and improving the parts that are actually
costing something.
